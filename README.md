# Clawd (attention-band)

A Claude Code mod: Clawd lives in a room above the prompt, acts out what your session is doing, and coaches you to get better at Claude, with levels, needs, daily quests and lessons.

## Install

In Claude Code:

```
/plugin marketplace add KolbyJackLabs/Clawdagotchi
/plugin install attention-band@kolbyjacklabs
```

Turn on auto-update under `/plugin` → Marketplaces → kolbyjacklabs, so new versions arrive on their own.

## Release

Bump `version` in `.claude-plugin/plugin.json` and push. Claude Code only ships an update when the version changes.
